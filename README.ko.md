# Minimal Theme Settings — 한국어 문서

전체 문서는 [minimal.guide](https://minimal.guide/)에서 확인할 수 있습니다.

> 이 문서는 원본 README를 한국어로 번역한 것입니다. 한국어판 자체의 설치 및 업데이트 안내는 [README.md](README.md)를 참고하세요.

## 개요

이 플러그인은 [Minimal Theme](https://community.obsidian.md/themes/minimal)와 함께 사용하며, Obsidian 설정 패널에서 테마를 사용자 지정할 수 있게 해줍니다. Minimal Theme 사용에 필수는 아니지만 사용을 권장합니다.

## 사용

- Minimal Theme가 필요합니다.
- 메뉴 리본, 툴팁, 제목 표시줄, 스크롤바 등을 제거해 Obsidian UI를 단순하게 만들 수 있는 [Hider](https://community.obsidian.md/plugins/obsidian-hider) 플러그인과 함께 사용할 수 있습니다.

## 설정

### 색 구성표

미리 설정된 색 구성표 사이를 전환하거나 Style Settings 플러그인을 사용해 직접 만들 수 있습니다.

- Atom
- Ayu
- Catppuccin
- Dracula
- E-ink(베타)
- Everforest
- Flexoki
- Gruvbox
- macOS
- Nord
- Rosé Pine
- Solarized
- Sky
- Things

### 배경 스타일

라이트/다크 모드에서 사용할 여러 배경 스타일을 제공합니다. 이 옵션은 단축키로 전환할 수 있습니다.

- **기본**: 사이드바 배경을 약간 더 어둡게 표시합니다.
- **낮은 대비**: 사이드바와 본문 패널에 같은 배경을 사용합니다.
- **높은 대비(라이트 모드만)**: 어두운 사이드바와 밝은 본문 패널을 사용합니다.
- **순수 검정(다크 모드만)**: 사이드바와 본문 패널에 순수 검정을 사용합니다.

### 사용자 지정

- 글꼴, 글꼴 크기, 줄 너비 설정
- 링크 밑줄
- 집중 모드
- 사용자 지정 아이콘
- 이미지 격자
- 표, 이미지, iframe 너비 설정
